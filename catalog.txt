1. HIGHLIGHTS & WHAT'S NEW IN VERSION 3.3.0 STABLE
-------------------------------------------------------------------------------

New Features & Typography Studio
4 ITEMS

. Advanced Font Studio & Local Font File Importer
Drag and drop or browse any local font file (.ttf, .otf, .woff, .woff2)
directly into Ocal Screen. Features real-time dynamic @font-face registration,
persistent custom font storage, and instant visual specimen previews.

. 1-Click Curated Google Fonts Library
Built-in catalog of 20+ creator-favorite Google Fonts categorized by sans,
serif, display, monospace, and handwriting styles with instant 1-click activation.

. Custom Google Font URL & Family Name Installer
Install any font from Google Fonts by family name or stylesheet URL with
automatic font-face loading and typography specimen validation.

. Redesigned Typography Combobox & Category Filter
Upgraded font selectors with search query filtering, typography family badges,
and instant "Install / Import Fonts" quick access.


Title & Annotation Improvements
3 ITEMS

. 100% WYSIWYG Preset Synchronization
Guaranteed visual parity between gallery preview thumbnails and video canvas
annotations. Preset fonts, capsule border radii (9999px pills), padding, text
shadows, and backdrops now render identically across editor and export.

. Dynamic Live Preview Text Bar
Interactive preview input bar in Titles & Text Styles allows typing once to see
all 12 preset styles preview the exact custom text with live formatting before
inserting.

. Mathematical Center-Anchored Placement
All newly inserted title presets, subtitles, and badges are automatically
centered precisely on the video canvas (X: 35%, Y: 40% for 30x20 boxes)
with centered flex alignment.


Bug Fixes & Stability
2 ITEMS

. Preset Text Insertion Name Collision
Resolved bug where clicking "Insert" on title presets inserted the card's
administrative name (e.g. "Social Handle Badge") instead of the rendered
styled text (@sampletitle • follow).

. Canvas & Exporter Badge Border Radii
Fixed issue where capsule pills and badges defaulted to sharp 4px corners
in playback and video export; now fully honors rounded-full and custom radii.


UI Polish & Theme Enhancements
1 ITEM

. Theme-Adaptive Style Cards
Eliminated pitch-black thumbnail boxes in light mode in favor of clean slate
surfaces and high-contrast, beautiful typography cards.

2. ADDITIONAL STUDIO CAPABILITIES & ARCHITECTURE
-------------------------------------------------------------------------------

* RE-ENGINEERED INSTALL & UPGRADE PIPELINE
  - Introducing intelligent upgrade detection: When updating an existing copy
    of Ocal Screen, Setup offers a Full Studio Upgrade that cleanly purges
    legacy runtime binaries, cached asars, and stale files before laying down
    the fresh v3.0.00 build.
  - Feels like a crisp, brand-new full installation every time.
  - All your user projects, recordings, presets, and preferences remain
    100% safe and untouched.

* PORTRAIT PRO WORKSPACE (9:16 SHORTS / REELS / TIKTOK)
  - Maximized Vertical View: Full-height video preview on the left eliminates
    wasted letterboxing, giving over 2x larger visual workspace.
  - Dual-Stack Studio Layout: Inspector and Timeline stacked ergonomically
    on the right, allowing real-time effect adjustments while scrubbing.
  - One-Click Layout Switcher: Effortlessly toggle between Auto, Portrait Pro,
    and Standard Stacked modes.

* COMPLETE EXPORT STUDIO HUB
  - Real-time resolution indicators (e.g. 1080x1920, 2560x1440, 3840x2160).
  - Multi-Format Rendering: Lossless MP4 (H.264 / AVC) and ultra-smooth GIF.
  - Granular Framerate Controls: 15, 24, 30, and 60 FPS options with loop
    toggles and upscale warning indicators.
  - Studio Progress Modal: Shimmer progress bar, active frame render counters,
    elapsed time stats, and clean error handling.

* HARDWARE-ACCELERATED RECORDING & CURSOR TELEMETRY
  - Windows Graphics Capture (WGC) helper: Smooth, low-latency screen capture.
  - Native Windows Cursor Engine: Zero-delay cursor capture with high-accuracy
    position tracking and click bounce dampening.

* 100% PRIVATE & ON-DEVICE
  - Zero cloud dependencies for video rendering and Whisper voiceover captioning.
  - No telemetric tracking: Your creative content stays on your machine.
